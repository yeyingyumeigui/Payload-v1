# DESIGN — 载荷方案设计器·本周技术总结

风格路由：技术工作总结 → 不命中三预设垂直领域 → 走通用设计原则（universal-only），按航天主题定制"深空科技风"。

## 1. 画布与母版（A/B/C 三区）

- 画布 1280×720，页面 padding 上下 20px、左右 70px
- **A 标题块** 0–120px：主标题 34px bold #E8EEF7，左对齐 x=70；副题/页眉线
- **B 内容区** 120–660px：全部正文/图/SVG
- **C 页脚条** 660–720px：左"文生载荷 · 载荷方案设计器"14px #5A6B84，右页码 NN/05 14px #5A6B84
- 封面 P1 与结束页 P5 用自定义全屏版式（省略 A/C 常规定位，P1 页码保留右下）

## 2. 色彩池（≤4 hex + 中性）

| 角色 | hex | 用途 | 面积 |
|------|-----|------|------|
| 深空底 | `#0B1B33` | 全篇背景（深海军蓝） | 主色 ≤60% |
| 星链蓝 | `#3B82F6` | 标题强调、图表主线、卡片描边 | 辅色 ≤30% |
| 轨道青 | `#22D3EE` | 次级线条、图标、分隔 | 辅色内 |
| 信号橙 | `#F59E0B` | 强调色：巨型数字、关键标注、CTA | ≤10%（hero 页≤18%） |
| 文本主 | `#E8EEF7` | 标题/正文亮字 | 中性 |
| 文本次 | `#93A5BE` | 副题/脚注/说明 | 中性 |

- 色彩节奏：P1/P4（hero/peak）强调色可至 15-18%；P2/P3（supporting）强调色≤5%；P5 收束克制
- 渐变方案：`linear-gradient(135deg,#0B1B33 0%,#132C52 60%,#0B1B33 100%)` 全篇底；卡片头 `linear-gradient(90deg,#3B82F6,#22D3EE)` 细条
- 半透明：卡片底 `rgba(59,130,246,0.07)`，描边 `rgba(147,165,190,0.25)`，SVG 星空星点 opacity 0.15~0.6

## 3. 字体系统（≤2 家族）

- 中文：**思源黑体**（Source Han Sans SC / 回退微软雅黑）；西文/数字：**Space Grotesk**（回退 Consolas/Arial）——"科技未来"气质，letterSpacing 标题 +1
- 层级：封面主标 64px bold / 页面主标 34px bold / 卡片小标 22-24px 600 / 正文 16-18px regular lineHeight1.55 / 巨型数字 96-110px bold（Space Grotesk）/ 锚点数字 44-56px bold / 脚注页码 14px
- 巨型数字必须与正文不同字重+西文字体

## 4. 密度与留白

- 常规页留白 ≤35%；P1 封面 40%、P4 hero 35%、P5 结束页 45%（围绕焦点留白）
- 容器填充率 ≥85%；卡片高≥380px 时正文≥100字；尾部标签条 marginTop:'auto' 钉底
- 焦点元素周围 ≥40px 呼吸空间

- 母版三区齐全（P1/P5 自定义但页码保留）；标题块无装饰小图；每页 L1 ≥30% B区；≤4 hex + 2 字体家族；相邻版式不重复；每页 ≥1 视觉锚点（≥44px）；P1→P2→P3→P4→P5 视觉重量差异显著（hero/supporting/supporting/hero/ending）；强调色按页映射表；P4 hero 锚点 ≥48px（96px ✓）；supporting 页（P2/P3）不用 hero 级视觉投入
