## ① 意图对齐

- **目标受众**：实训项目组 / 技术同事，周度技术工作汇报展示场合。
- **核心目标**：让观众相信——一周内以纯 Python 零依赖完成了航天级载荷设计器 v1→v5.3→v2 三轮迭代，五引擎物理内核可信（独立第一性原理复算零失败），工程质量有全绿自动化验证基线兜底；记住"五引擎 + 闭环救援 + 全绿验证"三个关键词。
- **PPT 长度**：5 页（短篇汇报）。Hero 配额：封面 + 第4页数据冲击页为视觉高潮；5 页短篇下按"封面必 hero + 中段 1 个高潮"执行。
- **视觉调性**：航天科技、深蓝星空、数据密集、工程严谨、克制留白。
- **内容边界**：只讲技术（五引擎、闭环评级与救援、v2 整改、验证矩阵、下周技术计划）；不讲商业/管理内容；不出现内部工具链细节（Bash shim 等环境坑不进 PPT）。

5 页单章结构（短篇不设目录页与章节扉页——目录↔扉页契约在 5 页篇幅下豁免，全篇 0 个 catalog、0 个 section）：

- Hero 页：P1 封面、P4 验证矩阵（2/5，短篇封面+高潮结构），两 hero 间隔 P2/P3 两个 supporting ✓
- rhythm：peak → transition → valley → peak → transition，无连续 3 页 valley ✓
