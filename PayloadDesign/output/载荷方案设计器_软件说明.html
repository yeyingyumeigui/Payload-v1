一、软件概述

1.1 软件是什么

载荷方案设计器是一款单机离线的 Windows 桌面工具：用户输入一组任务需求（业务/轨道/覆盖/频段/体制），软件在数秒内完成从需求解析到方案评价的全流程闭环设计，输出可直接汇报的载荷方案（框图、链路预算、单机清单、平台/运载匹配、评级评分、Word 报告）。

1.2 解决什么问题

传统流程痛点本软件的做法
指标拆解靠人工经验，口径不一需求→EIRP/G/T 反推全公式化，与知识图谱判据 id 对齐、可追溯
链路预算用 Excel 手搭，易漏项25 条工程约束（c-1~c-25）自动全检，雨衰/大气/指向/极化/实现损耗同源合成
天线/转发器/单机选型各自为政五维天线选型 + 货架优先三线编号 + 平台/运载自动匹配，一条链贯通
方案可行性判断滞后十项准则（6 硬 4 软）即时评级 A/B/C/D，不可行项直接给出修正建议
汇报材料重做一键导出 Word 报告（含 11 张矢量图栅格化嵌入）

二、设计流程：五步闭环 + 双回环

2.1 五步闭环

步骤引擎函数做什么关键输出

② 架构规划derive_geometry + cfg_to_params轨道几何推导（斜距/波束角/波束数）+ 体制映射θ_beam、N_geo、EIRP_req/GT_req 反推初值

③b 转发器方案plan_transponderEIRP 反推功放功率 + HPA 选型 + 信道化P_out、TWTA/SSPA/MPA 配置

2.2 双回环机制

  • 内环（平台可行性换天线）：初选方案质量/功耗超平台包络时，自动回退换更轻/更省电的天线方案，≤3 次迭代；
  • 外环（链路余量否决重选型）：链路校核发现余量不足且无法靠加功率解决时，携带排除清单重新选型，≤2 次；
  • 回环全程留痕，在「⑩ 约束校验与回环」页签可见每次迭代的触发原因与结果。

2.3 一键建议值闭环

「💡 一键建议值」按钮对当前配置反推推荐参数（口径、阵元数、波束数、带宽、功放等），应用后自动重算并评级——suggest_closed_loop 验证其收敛性（自检中 1 次迭代即达 A 级、0 项需人工调整）。

5.3 验证发现并修复的真实物理缺陷（T_sys 相控阵噪声遗漏）

这是本次验证最重要的产出——交叉验证抓出了一个此前所有测试都没发现的物理 bug：

项目修复前修复后

七、适用范围与限制

7.1 适用

  • 通信卫星（GEO/MEO/LEO/SSO/HEO）有效载荷方案论证与初步设计；
  • 业务类型：高通量宽带、广播电视、移动通信、手机直连 D2D、中继数传、军用抗干扰、窄带物联网；
  • 频段：L/S/C/X/Ku/Ka/Q/V + 激光星间链路；
  • 体制：透明/数字透明（DTP）/再生 × 固面/相控阵/伞状/大容量多波束/混合多波束。

7.2 限制（使用时须知）

  1. 深度为方案级：链路预算为典型值口径（雨衰用区域参考值而非 ITU-R P.618 逐站计算），不能替代详细设计阶段的逐链路精算；
  2. 货架库时效性：单机/平台/运载数据为知识库快照，工程引用前需与最新产品目录核对；
  3. GRASP 波束桥：仅支持偏置抛物面（F/D=1.31）PO 计算，其他反射面类型自动降级 Airy 解析近似；
  4. 覆盖示意图：世界地图仅海岸线地理参考，不含政治边界，正式出版需换用合规审图底图；
  5. 知识图谱依赖：ant_rx_path 等接收链节点若缺失，引擎按合成默认链兜底（已在 P3b 验证不遗漏噪声），但建议保持 KG 与引擎版本配套；
  6. Ka/Q/V 雨衰：高可用度（99.9%+）高纬度场景雨衰参考值可能偏保守，热带地区需实测修正。

九、常见问题

现象原因与处置
exe 双击无反应缺 Edge WebView2 Runtime → 安装后重试（Win11 一般自带）；可查 payload_designer_boot.log
评级 D看「⑩ 约束校验」页 fail 项：容量缺口→增波束/带宽；功率墙→换反射面或降 EIRP 需求；平台无解→减质量功耗
相控阵场景 G/T 与手算差 6dB手算若漏 T/R 组件 LNA 噪声会偏高——软件口径（含 tr_module NF≈2dB）为准
自定义参数不生效预览版是快照，请用 exe 或 --web 版实时重算
导出 Word 打开格式异常用 Microsoft Word（非 WPS 旧版）打开 .doc；打印/PDF 走浏览器内核更稳
