# 载荷方案设计器 · 软件说明（简要版）

**版本**：v4.1（2026-09-24）　**形态**：单机离线 Windows 桌面工具（单文件 exe，约 15MB）
**定位**：通信卫星有效载荷方案**快速设计与可行性校核**工具——输入任务需求，数秒内输出可汇报的完整载荷方案与 Word 论证报告，用于方案论证阶段的设计与比选。

---

## 一、软件做什么

用户给定一组任务需求（业务类型 / 轨道 / 覆盖区 / 频段 / 转发体制 / 天线类型），软件自动完成：

| 环节 | 内容 |
|---|---|
| 需求解析 | 覆盖几何推导（斜距 / 覆盖角 / 波束数），EIRP、G/T 指标反推 |
| 天线与转发器 | 五维天线选型（EIRP/G/T/质量/功耗/模式）、功放功率反推与 HPA 选型 |
| 单机与平台 | 货架单机清单（三线编号）、平台承载/供电匹配、运载火箭包络校核 |
| 链路校核 | 上/下行预算、25 条工程约束全检、雨衰按可用性折算、MODCOD 由 C/N 反推 |
| 评价输出 | 十项准则评级 A/B/C/D、六维评分、13 页签可视化、一键导出 14 章 Word 报告（19 张矢量图） |

## 二、核心特色（v4 / v4.1）

- **四指标耦合校核与一键修复**：覆盖区域、波束大小、波束数量、容量四项性能指标构成闭合约束链（覆盖角÷波束宽度→密铺波束数；波束宽度→天线口径 θ3dB≈70λ/D；波束数×带宽→容量与频谱）。任一指标改动，软件逐项校核 S1~S5 并**联立求解**给出修复值（如 N=113、B=111MHz、k=6 色），点击「⚡一键修复」自动回填重算；不可闭合时如实提示须换频段，不假装达标。
- **角度口径严格换算**：覆盖角支持三种口径（天线离轴角 / 地心角 / 地面足迹角），按严格球面三角互转——GEO 下 ±1.5° 离轴角 ≈ 8.47° 地心角 ≈ 942km 地面半径（相差 5.6 倍），避免口径混用导致的设计失真。
- **覆盖区 ↔ 国家双向判定**：正向给出算得覆盖区对全球 52 个国家/地区的覆盖率（全覆盖/部分/未覆盖）与国土边角仰角；反向由目标国推所需覆盖半径、波束电扫角与波束数。GEO 星下点（赤道）与波束指向中心（电扫）严格分离。
- **偏置反射面天线设计引擎**：以反射器口径 D_r、焦距 f、发射器中心偏置 h、馈源口径 d_feed 四项几何参数为输入（全部可配置），按物理光学严格二维数值积分计算照射/溢散效率、增益、口径积分远场方向图（E/H 双切面），并校核 F/D 区间、偏置间隙、边缘锥削等 7 项工程约束；仅反射面族天线（固面/伞状/大容量多波束/混合多波束）启用。
- **波束照射区轨道仿真**：轨道页覆盖区为**天线波束锥与地球的实际交线**（严格射线-球面求交），区别于可见性覆盖帽（仰角门限参考圈）；GEO 电扫指向、LEO 天底/过境均支持，导出 STK Ephemeris 复核。
- **全流程可追溯**：每条计算对齐知识图谱判据编号（c-1~c-25），异常分级 L1/L2/L3，回环留痕；GRASP/SATSOFT/STK 等效内置计算 + 标准格式文件导出双通道。

## 三、运行方式

| 形态 | 用法 | 说明 |
|---|---|---|
| 桌面 exe | 双击 `载荷方案设计器.exe` | 实时计算；需 Edge WebView2 Runtime（Win11 自带） |
| 网页版 | `python design_app.py --web` | 自动开浏览器，实时计算 |
| 预览版 | 打开 `载荷方案设计器_预览版.html` | 8 典型场景预计算快照，任意浏览器可看，无需 Python |

零外部服务依赖，断网可用；纯 Python 标准库计算引擎，无 numpy/scipy。

## 四、使用流程（五步）

1. **选场景**：8 个典型场景一键载入（GEO 高通量 / LEO 宽带 / D2D 直连等），或空白起步；
2. **配指标**：需求与轨道面板填覆盖角度（方案选项）；性能约束面板填波束大小/数量/容量；天线面板填口径或反射面几何（留空自动）；
3. **开始设计**：全流程计算 + 体制/天线替代方案对比（至多 6 案六维评分）；
4. **看结果**：②总览页查评级、四指标耦合校核（冲突可一键修复）、国家覆盖判定、反射面设计；④天线页查方向图；⑫轨道页查波束照射区；
5. **出报告**：一键导出 Word（14 章，含框图/信息流/方向图/覆盖图/雷达图，图片已栅格化嵌入，WPS/Word 直接打开）。

## 五、可信度与验证

- **独立物理验证**：`_verify_physics.py` 不复用引擎代码，第一性原理交叉核对 15 类物理量 × 10 场景，0 失败；
- **引擎自检**：反射面引擎 41 项自检（含解析对照 ∫|F|²dΩ=2π/(2q+1) 偏差 0.00%、网格收敛性）、轨道引擎含波束足迹 6 项解析校验；
- **全套回归**：24 项一键回归 + DOM 端到端 94 项 + 父项目 102 用例全绿；
- **冻结验证**：打包 exe 自检 8/8 场景（评级/导出/图栅格化）+ GUI 依赖检查通过。

## 六、使用边界

本软件面向**方案论证阶段**的快速设计与比选，输出为工程估算口径（经验系数均标注来源）；不替代详细设计阶段的 GRASP/STK 等专业工具精确仿真（软件提供标准格式导出接口供其交叉复核）。货架单机与平台参数为公开资料整理，实际选型以厂商最新数据为准。
