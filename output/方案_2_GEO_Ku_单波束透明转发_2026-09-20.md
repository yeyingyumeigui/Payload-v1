## 三、载荷方案

### 转发体制：透明转发 (Bent-Pipe)

星上仅做变频与放大，不做解调。技术成熟、成本低、时延小。

**载荷链路组成：**

```
  接收天线 → LNA → 下变频 DCONV → IMUX → TWTA/SSPA → OMUX → 上变频 UCONV → 发射天线
```

| 优势 | 局限 |
|------|------|
| 技术成熟度最高 | 波束固定、灵活性差 |
| 成本最低 | 噪声全链路累积 |
| 星上处理时延小 | 无星上交换能力 |

**适用场景**：固定业务广播、传统 VSAT、成熟轨道位
